# 卒中康复中的质量感知 EEG-fNIRS 量表估计

本项目探索：使用 EEG/fNIRS 信号估计卒中患者上肢运动功能量表，并根据每次信号质量动态调整两种信号的贡献，以减少重复量表评估的负担。

## 研究设想

训练时使用实际临床量表分数作为监督标签：

```text
EEG + fNIRS + 各自的质量指标 -> 模型 -> 估计 FMA-UE / ARAT
                                               |
实际量表分数 --------------------------------> 训练误差
```

量表是训练目标，不是主模型的输入。部署推理只需要 EEG、fNIRS 和质量指标。模型的质量门控只读取信号质量指标，输出 EEG/fNIRS 的融合权重。

主模型位于 `src/stroke_qafusion/models/quality_aware_temporal.py`。EEG/fNIRS 质量代理指标位于 `src/stroke_qafusion/quality/`。旧的 `quality_gated.py` 是需要临床基线输入的残差融合对照，不是量表稀疏采集主模型。

## 公开数据集限制

拟用数据集包括 16 名患者、84 次康复记录，并提供 FMA、ARAT 及同步 EEG/fNIRS 信号。论文列出的是康复前和康复后的临床分数；并非每次 EEG/fNIRS session 都有对应量表。因此：

- 不要把基线或康复后分数复制到中间 session，当作这些 session 的真实标签。
- 当前数据可用于探索信号变化与前后量表变化的关系、验证预处理和质量门控流程。
- 只有 16 名患者，模型的患者外泛化证据有限；必须按患者分组划分，不能按窗口/epoch 随机拆分。
- 在确认量表时间点与信号记录能够匹配之前，不启动量表预测训练。

公开数据集 DOI：<https://doi.org/10.6084/m9.figshare.28904942>。使用时请引用数据集及其论文。原始数据不得提交到 Git。

## 开发步骤

1. 解压后检查 README、临床量表表格和文件命名规则。
2. 生成患者、session、run、任务手及记录时间的清单。
3. 核对量表采集时间，只关联确实匹配的标签。
4. 实现 EEG/fNIRS 预处理与质量指标，并整理为同一时间窗或同一次 session 的样本。
5. 先建立临床量表预测基线：EEG 单模态、fNIRS 单模态、普通融合、质量门控融合。
6. 使用按患者分组的交叉验证；报告 MAE、RMSE、相关性，并测试低质量/缺失模态时的性能。
7. 在更多独立患者数据上验证后，才讨论减少临床量表频率的临床效用。

## Linux 环境

预期 Python 3.10 或更高版本。先安装信号处理依赖，待数据结构确认后再安装 PyTorch：

```bash
python -m pip install -e '.[signals]'
python -m pip install -e '.[train]'
```

PyTorch 版本需结合服务器 CUDA 环境确定。原始数据与中间文件放在 Git 工作区之外。

## EEG 质量指标说明

当前 EEG 质量函数输出有效样本比例、平直通道比例、振幅异常比例、高频功率代理量及工频噪声比例。高频功率只能作为肌电/噪声代理指标；若没有 EOG/EMG 标注，不能称为已确认的伪迹标签。

## fNIRS 质量指标说明

当前 fNIRS 质量函数输出有效样本比例、平直通道比例、导数尖峰代理量及振幅异常比例。光源-探测器接触质量、波长特异信噪比等指标需要结合原始光强、波长和光极元数据计算。
