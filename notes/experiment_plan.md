# 实验方案：事件时间对齐的质量感知运动反应识别

## 当前主任务

暂定主结局为 trial 级“运动反应 / 无运动反应”。标签依据目标手、左右刺激事件和实际记录核对；EEG 文件中的 EMG 只用于核实标签/动作执行，不作为模型输入。最终标签规则必须在查看事件文件和数据集预处理脚本后固定。

本任务是康复任务中的运动状态识别，不等同于预测康复结局，也不等同于替代 FMA-UE/ARAT。

## 模型输入与融合

- EEG 与 fNIRS 分别预处理，避免原始采样点直接重采样拼接。
- 围绕刺激事件生成事件相对时间片特征。
- 为每个模态、每个时间片计算局部质量指标。
- 将质量、分支预测熵和相对事件时间输入逐时间片门控，得到 EEG/fNIRS 权重序列。
- 使用 GRU 汇总加权后的时间特征序列，输出 trial 类别。
- 可选地在确有量表标签的 session 上增加 FMA-UE 辅助损失；未测量的 session 必须屏蔽该项损失。

模型接口详见 `notes/temporal_quality_fusion.md`。

## 最小基线与消融

1. EEG 单模态分类。
2. fNIRS 单模态分类。
3. 特征拼接或固定权重融合。
4. 单个 trial 级质量门控。
5. 逐时间片质量门控。
6. 逐时间片质量门控 + 分支误差校准。
7. 逐时间片质量门控 + 局部信号损坏训练。

逐步加入模块，避免同时改动太多而无法判断性能变化来源。

## 鲁棒性评估

- 对局部时间片分别施加 EEG 噪声/坏道/幅度剪切，或 fNIRS 漂移/尖峰/通道失效。
- 检查被损坏区段的对应模态权重是否下降，未损坏区段是否基本保持。
- 对轻度损坏前后的分类输出计算一致性；严重损坏和模态缺失单独报告。
- 报告 balanced accuracy、macro-F1、AUROC、Brier/ECE，以及各损坏强度下的性能变化。
- 报告权重-质量和权重-分支误差之间的关系，不能只展示权重曲线。

## 数据划分与局限

- 按患者分组；同一患者的全部 session/run/trial 只能出现在一个数据折。
- 标准化、特征选择、阈值选择和校准均只在训练折拟合。
- 数据集约 16 名患者，重复 trial 不等于独立患者。结果定位为探索性方法验证。
- 不把前测或后测 FMA/ARAT 复制给中间 session。
- 时间片宽度、局部质量指标和事件标签须在查看原始文件后确定。
