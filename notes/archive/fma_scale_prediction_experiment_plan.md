# 归档：FMA-UE/ARAT 结局预测方案

> 这份方案保留为历史版本。当前仓库主线已转为“事件时间对齐的逐时间片质量门控运动任务识别”；不要将本文件中的 FMA 预后预测目标当作当前主任务。

## 原方案的临床预测目标

- 主要候选：随访 FMA-UE，模型输入包含基线 FMA-UE。
- 次要候选：随访 ARAT。
- 随访评分只能作为目标值，不能作为模型输入。

## 原方案的最小对照实验

1. 仅使用临床信息的模型。
2. 临床信息 + EEG。
3. 临床信息 + fNIRS。
4. 临床信息 + EEG + fNIRS 的普通融合模型。
5. 以临床模型为基准、由质量指标控制 EEG/fNIRS 修正量的质量门控模型。

## 原方案的质量门控假设

质量特征只调节 EEG/fNIRS 对临床预测的修正量。某个模态质量差或缺失时，该模态的修正应减弱，临床基准预测仍然保留。

## 仍适用的数据规则

- 按患者划分数据；同一患者的所有 session 必须放在同一折。
- 插补、标准化、特征选择和门控训练都只能在训练折内拟合。
- 公开队列只有 16 名患者且临床量表主要是前后测量，结论应限定为探索性。
- EEG 质量函数提供的是透明的信号代理指标，不代表经临床验证的伪迹标签。
